Régénérer un alignement différent

Avant le match, choisissez le bloc 1. En cours de match, choisissez le prochain bloc : les blocs antérieurs seront conservés.

Réajustement immédiat

Blessure ou indisponibilité

Les blocs antérieurs sont conservés. Le bloc choisi et tous les suivants sont recalculés. Pour une blessure entre deux blocs, choisissez le prochain bloc.

Installer gratuitement sur iPhone

  1. Ouvrir l’adresse de l’application dans Safari.
  2. Toucher Partager (carré avec flèche vers le haut).
  3. Choisir Sur l’écran d’accueil, puis Ajouter.

Après une première ouverture en ligne, l’application fonctionne hors connexion. Les données restent dans Safari sur cet appareil.
